# Changelog

All notable changes to Are You Sure? are documented here.

---

## [1.0.1] - 2026-10-04

### Changed

- **One captcha per kind of action** - A solved captcha now unlocks a whole kind of action (attack
  Pig, break Oak Log, place Stone, use Bread...) that can be repeated freely. Any other action asks
  again. Swinging at the air or using an empty hand never resets the pass. The pass expires after
  30 seconds of inactivity by default.
- **Redesigned screen** - Dark panel with a red header, step indicator, icon of the targeted block
  or item, word-wrapped question, captcha box that wobbles and shakes on a wrong answer, attempt
  counter, input hint, success and failure sounds.
- **License** - The project is now licensed under the Apache License 2.0.
- **Code layout** - Gameplay code is shared per Minecraft version in `common/`, loader projects only
  keep their entry point. The per-target branches are generated by `scripts/split-branches.sh`.

### Added

- **Admin command `/areyousure`** - `status`, `enable`, `disable`, `player <targets> enable|disable|reset`,
  `only <targets>`, `resetplayers`, `codelength <3-10>`, `timeout <seconds>`, `challenge <targets>`.
  Settings are stored per world in `areyousure.json` and synced to clients.
- **Optional networking** - The mod can now run on the server. The channel is optional on both
  sides: a modded client still works on a server without the mod, and the server never sends the
  payload to a client that does not have it.
- **Spectators** are no longer asked anything.

### Modifications

- **Un captcha par type d'action** - Un captcha résolu débloque maintenant tout un type d'action
  (attaquer un cochon, casser une bûche de chêne, poser de la pierre, manger du pain...) répétable à
  volonté. Toute autre action redemande. Frapper dans le vide ou cliquer main vide ne réinitialise
  jamais le passe. Le passe expire après 30 secondes d'inactivité par défaut.
- **Écran repensé** - Panneau sombre avec bandeau rouge, indicateur d'étape, icône du bloc ou de
  l'objet ciblé, question sur plusieurs lignes, captcha qui ondule et tremble en cas d'erreur,
  compteur d'essais, texte d'aide dans le champ, sons de réussite et d'échec.
- **Licence** - Le projet passe sous licence Apache 2.0.
- **Organisation du code** - Le code est partagé par version de Minecraft dans `common/`, les
  projets loader ne gardent que leur point d'entrée. Les branches par cible sont générées par
  `scripts/split-branches.sh`.

### Ajouts

- **Commande admin `/areyousure`** - `status`, `enable`, `disable`, `player <cibles> enable|disable|reset`,
  `only <cibles>`, `resetplayers`, `codelength <3-10>`, `timeout <secondes>`, `challenge <cibles>`.
  Les réglages sont sauvegardés par monde dans `areyousure.json` et synchronisés avec les clients.
- **Réseau optionnel** - Le mod peut maintenant tourner sur le serveur. Le canal est optionnel des
  deux côtés : un client moddé fonctionne sur un serveur sans le mod, et le serveur n'envoie jamais
  le paquet à un client qui ne l'a pas.
- **Les spectateurs** ne sont plus interrogés.

## [1.0.0] - 2026-09-30

### Added

- **Confirmation screen** - Attack, use and pick-block inputs are intercepted through the loader's
  `InteractionKeyMappingTriggered` event and cancelled until the player confirms.
- **Captcha step** - A random 6 character code drawn with colored, vertically scattered letters and
  noise dots. A wrong answer regenerates the code.
- **Single-use pass** - Solving the captcha allows exactly one action: the pass is consumed when the
  key is released, or expires after 10 seconds if unused.
- **Action description** - The prompt names the targeted block, entity or held item.
- **Translations** - English and French.
- **Loaders** - NeoForge and Forge for Minecraft 1.21.1 and 26.1.2. Client-side only.

### Ajouts

- **Écran de confirmation** - Les actions attaque, utilisation et pick-block sont interceptées via
  l'événement `InteractionKeyMappingTriggered` du loader et annulées jusqu'à confirmation.
- **Étape captcha** - Un code aléatoire de 6 caractères affiché avec des lettres colorées, décalées
  verticalement, et du bruit visuel. Une mauvaise réponse régénère le code.
- **Passe à usage unique** - Résoudre le captcha autorise une seule action : le passe est consommé au
  relâchement de la touche, ou expire après 10 secondes s'il n'est pas utilisé.
- **Description de l'action** - Le message nomme le bloc, l'entité ou l'objet ciblé.
- **Traductions** - Anglais et français.
- **Loaders** - NeoForge et Forge pour Minecraft 1.21.1 et 26.1.2. Uniquement côté client.
