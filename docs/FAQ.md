# FAQ

**Is this a joke?**
Yes. Are you sure you want to install it?

**Does the server need the mod?**
No. The client works alone on any server. Install it on the server too if you want the
`/areyousure` admin command.

**Can I disable it for a moment?**
In singleplayer or as a server operator: `/areyousure disable`. Otherwise, remove the jar.

**Do I have to solve a captcha for every single hit?**
No. One captcha unlocks one kind of action (attack Pig, break Oak Log, place Stone...). Repeat it
as much as you want. Any other action asks again, and the pass expires after 30 seconds of
inactivity by default (`/areyousure timeout`).

**Why does the game keep running while I type the captcha?**
Because it is funnier that way.

**Does it block walking, jumping or opening the inventory?**
No. It covers interactions: breaking, attacking, using, placing, opening containers, talking to
villagers, pick-block.

**Can I use it in a modpack or a video?**
Yes, the mod is licensed under Apache 2.0.

# FAQ (Français)

**C'est une blague ?** Oui. Êtes-vous sûr de vouloir l'installer ?

**Le serveur a-t-il besoin du mod ?** Non, le client fonctionne seul. Installez-le sur le serveur pour avoir la commande `/areyousure`.

**Puis-je le désactiver ?** En solo ou en tant qu'opérateur : `/areyousure disable`. Sinon, retirez le jar.

**Faut-il un captcha à chaque coup ?** Non. Un captcha débloque un type d'action (attaquer un cochon, casser une bûche, poser de la pierre...). Répétez-la autant que vous voulez ; toute autre action redemande, et le passe expire après 30 secondes d'inactivité par défaut (`/areyousure timeout`).

**Pourquoi le jeu continue pendant le captcha ?** Parce que c'est plus drôle.

**Est-ce que ça bloque la marche, le saut ou l'inventaire ?** Non, seulement les interactions :
casser, attaquer, utiliser, poser, ouvrir un conteneur, parler aux villageois, pick-block.

**Puis-je l'utiliser dans un modpack ou une vidéo ?** Oui, le mod est sous licence Apache 2.0.
