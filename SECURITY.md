# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a vulnerability

Please do not open a public issue. Report it privately through a
[GitHub private security advisory](https://github.com/laforetbrut/mods-mc-areyousure/security/advisories/new).
You will get an answer as soon as possible.

# Politique de sécurité

[GitHub private security advisory](https://github.com/laforetbrut/mods-mc-areyousure/security/advisories/new).
